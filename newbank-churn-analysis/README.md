# Newbank — Fee Revenue & Customer Analysis

**Problem:** A digital neobank needed to understand its fee-based
revenue and tie each transaction back to customer context
(plan, tenure, country) to support retention and churn analysis.

**Approach:** Built an enriched transaction dataset in BigQuery —
joined raw transactions to the users table, isolated completed
fee events, and mapped uncategorised transactions to clear
business labels.

**Tools:** Google BigQuery, Standard SQL

**Outcome:** A clean, analysis-ready table powering revenue and
retention dashboards in Power BI / Looker Studio.
